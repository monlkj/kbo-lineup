# KBO 올스타 매니저

실제 KBO 선수 기록으로 구성한 브라우저 구단 운영 게임입니다. 인원과 카드 수는 `data/catalog-meta.json`을 참고하세요. 현역·은퇴 선수 모두 KBO 선수 ID로 구분하고, 카드에 실제 선수 사진과 시즌별 확인된 수비 포지션을 표시합니다.

## 실행과 검증

```sh
cd kbo-lineup
npm ci
npm run dev
npm test
npm run build
```

## 게임

구단 코드와 선호 구단으로 입장한 뒤 우편함에서 창단 선물을 받습니다. 새 클럽하우스에서 선수 도감, 수상자 필터, 상세 능력치, 선수단, 타순과 선발 5명·불펜 3명, 구단·연도 덱 효과, 144경기 시즌 리그와 포스트시즌을 사용할 수 있습니다.

타순·투수 메뉴에서 리그 시작 선수단을 받고 자동 편성하면 바로 경기를 시작할 수 있습니다. 경기 참여 경험치 10마다 성장 포인트 3을 받으며 선수단 상세 화면에서 능력치에 배분합니다. 컨디션과 투수 피로는 경기에 반영됩니다. 경기 승패·개인 기록·지난 시즌은 구단별로 저장됩니다. 상점의 수상자 전용팩은 검증된 골든글러브·MVP·올스타 이력이 있는 시즌 카드만 지급합니다.

능력치는 실제 시즌 기록을 게임 규칙으로 환산한 값입니다. 구종 자료는 검증되지 않아 임의로 넣지 않습니다. 포스트시즌은 와일드카드, 준플레이오프, 플레이오프, 한국시리즈 순서입니다. 리그 결과는 게임 시뮬레이션이며 실제 KBO 경기 기록이 아닙니다. 투수 승패는 선발 기준으로 간소화합니다. 시즌 결산은 게임 기록이며 실제 수상 태그를 만들지 않습니다.

## 저장과 기존 기록

현재 브라우저의 localStorage에 구단 코드별로 저장합니다. 계정 인증이나 기기 간 동기화 기능은 없습니다. 일일 보상은 한국 시간 기준 하루 한 번입니다.

v18 저장 원본을 보존하고 v20 저장으로 옮깁니다. 구버전의 무작위 카드는 이름·팀·연도가 실데이터와 유일하게 일치할 때만 가져옵니다. 일치하지 않는 카드는 새 선수단에서 제외되며 원본은 v18 저장에 남습니다. 확인된 수비 위치와 맞지 않는 예전 라인업은 비웁니다. 통화와 소지품은 유지합니다. v20 초기화 후 구버전 저장을 다시 자동으로 가져오지 않습니다.

## 자료 범위

[수집 절차와 출처](scripts/README.md)를 참고하세요. 올스타 표시는 수집한 연도의 공식 베스트 선발 명단만 반영하며 후보자 명단을 수상·선발로 취급하지 않습니다. 사진은 확인된 선수 프로필 사진으로, 카드 시즌의 촬영 사진과 다를 수 있습니다.
