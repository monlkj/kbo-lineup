# KBO 올스타 매니저

실제 KBO 선수 기록으로 구성한 브라우저 구단 운영 게임입니다. 인원과 카드 수는 `data/catalog-meta.json`을 참고하세요. 현역·은퇴 선수 모두 KBO 선수 ID로 구분하고, 카드에 실제 선수 사진과 시즌별 확인된 수비 포지션을 표시합니다.

## 실행과 검증

```sh
cd kbo-lineup
npm ci
npm run dev
npm test
npm run build
```

## 게임

구단 코드와 선호 구단으로 입장한 뒤 우편함에서 창단 선물을 받습니다. 새 클럽하우스에서 선수 도감, 수상자 필터, 상세 능력치, 선수단, 타순과 선발 5명·불펜 3명, 구단·연도 덱 효과, 144경기 시즌 리그와 포스트시즌을 사용할 수 있습니다.

창단할 때 선택 구단의 기본 선수 26명과 야수·선발 5명·불펜 3명 편성을 함께 지급하므로 바로 리그 경기를 시작할 수 있습니다. 과거 구단은 확인된 자료가 부족한 포지션을 동일 계열 구단 기록으로 보완합니다. 기본 선수단을 받지 않은 기존 구단도 재접속 시 한 번 지급합니다. 경기 참여 경험치 10마다 성장 포인트 3을 받으며 선수단 상세 화면에서 능력치에 배분합니다. 컨디션과 투수 피로는 경기에 반영됩니다. 경기 승패·개인 기록·지난 시즌은 구단별로 저장됩니다. 상점의 수상자 전용팩은 검증된 골든글러브·MVP·올스타 이력이 있는 시즌 카드만 지급합니다.

능력치는 실제 시즌 기록을 게임 규칙으로 환산한 값입니다. 구종 자료는 검증되지 않아 임의로 넣지 않습니다. 포스트시즌은 와일드카드, 준플레이오프, 플레이오프, 한국시리즈 순서입니다. 리그 결과는 게임 시뮬레이션이며 실제 KBO 경기 기록이 아닙니다. 투수 승패는 선발 기준으로 간소화합니다. 시즌 결산은 게임 기록이며 실제 수상 태그를 만들지 않습니다.

## 스타, 선수 한도와 스카우트

선수 보유함은 기본 100명입니다. 스타 500으로 20칸씩 최대 300명까지 확장할 수 있습니다. 기존에 한도를 초과한 선수는 삭제하지 않습니다. 편성되지 않은 선수는 확인 후 방출하고 1,000 P를 받습니다. 편성된 선수와 고급 변경권 선택 중인 선수는 방출·스카우트 재료로 사용할 수 없습니다.

- 시그니처 스카우트: 3,000 S 또는 플래티넘 이상 재료 3명 + 100,000 P
- 레전드 스카우트: 5,000 S 또는 재료 5명 + 200,000 P
- 스타 상점: 구단선택팩, 수상자 전용팩, 고급·선택·보호 변경권, 선수 보유함 확장

스카우트는 표시된 등급을 확정 지급합니다. 대상 구단에 해당 선수 자료가 없으면 재화나 재료를 소모하지 않습니다. 선수 보유 한도가 차면 스타 스카우트와 팩 개봉을 막으며, 일괄 개봉은 빈 공간만큼만 진행하고 남은 팩을 보존합니다. 재료 스카우트는 재료 소모 후 최종 인원으로 검사합니다.

## 고유능력 변경권

| 변경권 | 동작 | 플래티넘 미만 선수 | 플래티넘·시그니처 선수 | 레전드 선수 |
|---|---|---|---|---|
| 일반 | 기존 전체 세트를 즉시 교체 | 최대 히어로 | 최대 플래티넘 | 최대 플래티넘 |
| 고급 | 기존/신규 전체 세트 중 선택 | 사용 불가 | 1번 플래티넘 확정 | 1번 레전드 10% / 플래티넘 90% |
| 선택 | 선택 슬롯만 교체 | 최대 히어로 | 최대 플래티넘 | 최대 플래티넘 |
| 보호 | 선택 슬롯을 유지하고 나머지를 교체 | 최대 히어로 | 최대 플래티넘 | 최대 플래티넘 |

고급 변경권은 플래티넘 이상 선수 전용입니다. 1번 슬롯만 상위 능력을 보장하고, 2·3번 슬롯은 카드 등급과 관계없이 노말·히어로·플래티넘 중 추첨합니다. 레전드 10%는 이 게임에 설정한 확률이며 다른 게임의 공식 확률이라는 뜻이 아닙니다. 이전 규칙으로 이미 뽑은 선택 대기 세트는 재추첨하지 않고 보존합니다. 다른 변경권의 제한은 새로 생성하는 능력에 적용하며 보호한 슬롯은 유지합니다. 고급 변경권은 사용 시 1장을 소모하고 선택 대기를 저장하므로 새로고침해도 재소모·재추첨되지 않습니다. 한 슬롯뿐인 카드에는 보호 변경권을 소모하지 않습니다. 초기 영입과 스카우트에도 카드 등급별 최대 능력 등급을 적용하고, 구버전에 잘못 지급된 등급 초과 능력은 불러올 때 정리합니다.

## 저장과 기존 기록

현재 브라우저의 localStorage에 구단 코드별로 저장합니다. 계정 인증이나 기기 간 동기화 기능은 없습니다. 일일 보상은 한국 시간 기준 하루 한 번, 포인트 복권 3장과 30스타를 우편함으로 지급합니다.

v18 저장 원본을 보존하고 v20 저장으로 옮깁니다. 구버전의 무작위 카드는 이름·팀·연도가 실데이터와 유일하게 일치할 때만 가져옵니다. 일치하지 않는 카드는 새 선수단에서 제외되며 원본은 v18 저장에 남습니다. 확인된 수비 위치와 맞지 않는 예전 라인업은 비웁니다. 통화와 소지품은 유지합니다. v20 초기화 후 구버전 저장을 다시 자동으로 가져오지 않습니다.

## 카드 화면

실제 선수 프로필 사진을 세로형 카드로 표시합니다. 좌상단은 게임 OVR, 우상단은 카드 등급, 아래는 이름·시즌과 경험치에 따른 레벨·수비 포지션입니다. 타순·투수 화면에서는 사용자가 편성한 SP/RP/CP 역할을 표시하며 실제 시즌 기록의 포지션을 바꾸지는 않습니다. 도감·선수단·훈련·영입 결과·라인업에서 같은 카드 스타일을 사용합니다.

## 보상과 개봉 수량

스타는 창단 500 S, 일일 출석 30 S, 우리 팀의 한국시리즈 우승 500 S로 제한합니다. 무제한 스타 충전과 정규리그 승리마다 주던 스타는 제거했습니다. 기존에 이미 보유한 재화는 유지하며, 미수령 창단 스타 우편은 새 기준인 500 S로 조정합니다.

창단 포인트 복권 10장, 출석 3장, 정규리그 승리 2장·무승부/패배 1장, 한국시리즈 우승 10장을 우편함으로 보냅니다. 우편 수령 후 보관함에서 복권을 사용하면 포인트가 들어옵니다. 기존 고정 창단 지원금 미수령 우편도 복권으로 전환합니다. 선수 방출 대가는 기존처럼 1,000 P입니다.

복권 1장당 10,000 P(50%), 30,000 P(30%), 50,000 P(15%), 100,000 P(4%), 500,000 P(1%)이며 결과 화면에서 확률을 확인할 수 있습니다. 복권은 선수 한도와 관계없이 사용할 수 있습니다.

보관함의 선수팩과 포인트 복권은 1개·10개·모두 개봉을 지원합니다. 10개 버튼은 10개 이상 보유 시 활성화됩니다. 선수팩은 보유함의 빈칸만큼만 열고 나머지 팩을 남깁니다.
