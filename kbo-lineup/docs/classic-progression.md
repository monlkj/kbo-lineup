# 일반판 컴프야 흐름을 참고한 성장·조합

V 시리즈 대신 일반판의 탐색/영입, 동일 선수 한계돌파, 3~5장 조합과 7장 선택 흐름을 사용한다. 다음 금액·확률·레시피는 이 웹게임의 공개 규칙이며, 원작 공식 확률이나 전체 선수별 재료표가 아니다.

## 레전드

3,000 P로 후보 1명을 탐색하고 12시간 대기한다. 대기 중에는 500 S와 3,000 P로 재탐색할 수 있다. 재탐색은 기존 등록을 해제하지만 카드를 소모하지 않는다. 후보는 실제 MVP 이력이 있는 도감 선수 중 선택하며 해당 카드의 실존 선수/연도/포지션/사진/수상 기록을 유지한다. MVP가 레전드라는 공식 분류를 뜻하지 않으며 이 게임의 카드 등급 설정이다.

동일 구단·가까운 연도 우선으로 결정한 서로 다른 선수의 지정 플래티넘 6장, 레전드와 같은 구단의 실제 올스타/MVP/골든글러브 플래티넘 각 1장, 같은 구단의 국가대표 플래티넘 1장, 구단·연도·이름이 지정된 코치 2장으로 총 12칸을 채운다. 전신 구단은 게임 규칙상 같은 계열로 인정한다. 지정 선수 6명과 코치 2명은 실제 재료가 필요하다. 만능 재료는 수상/국가대표 칸에만 최대 2개 사용한다. 영입 증서 1장과 1,000,000 P로 표시된 후보를 영입하며 그때만 재료를 소모한다. 영입 증서는 한국시리즈까지 리그 시즌을 완료하면 1장씩 우편으로 지급한다. 재료는 후보 탐색 후 리그 코인 10개로 무작위 재료팩을 교환해 모은다. 12칸은 각각 1/12 확률이며 이미 모은 재료가 다시 나올 수 있다. 선택 칸 50,000 P 직접 구매는 종료했다.

국가대표는 KBO 공식 최종 명단에서 확인한 2023 개최 항저우 대표 중 프로 선수 23명만 대상으로 한다. 부족했던 실제 2023 시즌 카드 13장은 기존 수집 KBO 기록·수비 포지션·사진 출처로 보충했다. 학생 선수는 KBO 카드로 만들지 않는다. 국가대표 태그는 `cardType:NATIONAL`이며 골글/MVP/올스타 수상 기록과 구분한다. 코치는 출처가 확인된 2023년 10개 구단 각 2명을 재료로 사용하고 선수 정원·포지션과 분리한 보관함 아이템으로 저장한다. 코치의 선수 시절 포지션이나 임의 능력치·사진을 만들지 않는다.

기존 9칸 후보를 열면 같은 후보와 지정 선수 조건을 유지하며 12칸으로 전환한다. 기존 등록은 새 조건과 일치할 때 유지하고, 조건이 달라 해제되는 카드도 소모하지 않는다. 기존 보유 선수·아이템·통화는 보존한다. 선수별 지정 명단과 코치 연도 선정은 이 게임의 레시피이며 원작의 전체 선수별 공식 재료표를 복제한 것은 아니다.

## 시그니처 각성

+20 플래티넘을 동일 선수/연도의 시그니처로 바꾼다. 대상 포지션에 따라 정확/파워/선구/주력/수비 또는 제구/구위/체력 중 능력치를 직접 선택한다. 선택한 능력치가 **95 초과(96 이상)**인 골든글러브/MVP 카드 **5장**, 또는 일반/국가대표/올스타 카드 **10장** 중 한 경로를 사용한다. 두 경로를 섞거나 OVR·연도·구단 합산 조건으로 대체하지 않는다. 선택 능력치가 없는 포지션의 카드는 재료가 될 수 없다.

어느 경로든 계약서 1장과 100,000 P가 필요하다. 각성 만능 재료로 각 선수 재료를 대체할 수 있다. 대상의 고유 ID, 강화, 성장, 경험치, 고유능력과 편성을 유지한다. 능력 세트는 등급 상한 검증을 거친다. 재료 선택은 화면을 떠나면 초기화되며 실행 전에는 소모되지 않는다. 실제 수상 이력이 없는 카드는 골글/MVP 재료가 될 수 없으며, 국가대표도 확인된 명단의 시즌만 인정한다.

## 강화·한계돌파

- 기본 +10 상한. 스페셜 이상 대상에 동일 선수 재료 1장(연도 무관)으로 상한 +2, 5회까지 +20. 실제 강화 단계는 별도로 올린다.
- 포인트 돌파: 다음 돌파 횟수 × 10,000 P. 재료 노멀10%, 레어20%, 스페셜40%, 히어로60%, 플래티넘80%, 시그니처/레전드100%.
- 스타 돌파: 다음 돌파 횟수 × 100 S와 동일 선수 재료, 성공100%. 돌파권: 권1장만 사용, 성공100%.
- 강화: 다음 단계 × 3,000 P 또는 ×50 S. 포인트는 100%에서 현재 강화 단계당 10%p 감소, 최소10%. 스타100%.
- 실패해도 대상 강화/상한은 떨어지지 않으며, 시도 비용과 재료는 소모된다. 기존 +10 초과 저장본은 기존 강화 단계가 손실되지 않도록 상한을 추론한다.

## 조합

일반·포지션은 3~5장, 무료. 포지션은 모든 재료가 그 포지션을 소화하며 결과도 동일 주 포지션이다. 스타 조합은 500 S, 입력 최고 등급 보장, 최대 플래티넘. 시그니처/레전드는 조합에서 보호한다.

일반·포지션은 입력 최저 등급 기준이며 장수에 따른 차이는 없다.

|기준|결과|
|---|---|
|노멀|노멀70%, 레어25%, 스페셜5%|
|레어|노멀10%, 레어65%, 스페셜25%|
|스페셜|레어15%, 스페셜65%, 히어로20%|
|히어로|스페셜20%, 히어로65%, 플래티넘15%|
|플래티넘|히어로30%, 플래티넘70%|

히어로 이상 결과 또는 스타 조합은 같은 등급 후보 7장을 보여주고 섞은 뒤 1장을 선택한다. 후보는 중복될 수 있다. 각 칸은 1/7. 낮은 등급 결과는 1장 즉시 수령한다.

## 아이템 공급

기능 화면에서 돌파권500 S, 레전드 만능 재료1,000 S, 시그니처 만능 재료500 S, 각성 계약서1,500 S. 스타는 기존 희소 보상 정책을 유지한다. 보관함에서 이 아이템을 누르면 해당 기능 화면으로 이동하며 선수팩으로 개봉하지 않는다.

## 저장·소모 보호

편성 선수, 고스변 선택 중 선수, 레전드 등록 재료는 소모에서 보호한다. 후보와 등록, 탐색 만료 시각, 조합 후보 및 섞은 순서는 구단 저장본에 보존한다. 조합은 후보 생성 시 재료를 한 번만 소모하고 이후 재추첨하지 않는다. 결과를 선택할 때까지 다른 기능 입력을 막는다. 모든 거래는 재료/수량/재화/정원을 검증한 뒤 한 번에 반영한다.

## 고스변 확률 및 시험용 지원

사용자 요청으로 레전드 카드 고급 변경권의 첫 슬롯은 레전드35%, 플래티넘65%로 변경했다. 일반·선택·보호 변경권은 계속 최대 플래티넘이고 2·3번 슬롯도 최대 플래티넘이다. 이미 생성된 대기 세트는 바꾸지 않는다.

모든 구단 화면 상단의 `시험용 재화 무한 지원` 버튼은 현재 브라우저의 구단 저장에 포인트·스타 각각 최소999,999,999, 일반/고급/선택/보호 변경권과 한계돌파권·각성 계약서·두 만능 재료 각각 최소999장, 구단선택/수상자/일반 선수팩 각각 최소100장을 지원한다. 반복 사용으로 소모한 만큼 충전하며 더 많이 가진 수량은 줄이지 않는다. 선수·편성·기존 아이템 ID를 보존하고 시험용 지원 사용 여부를 표시한다. 진행 중인 세트/조합 선택은 먼저 완료해야 한다.

## 리그 진행·보상과 레전드 희소성 개편

- 일반·구단선택·수상자 등 선수팩의 최대 카드 등급은 플래티넘이다. 실제 MVP 이력이 레전드 카드 자동 지급으로 이어지지 않는다. 기존 보유 레전드는 그대로 보존한다.
- 과거 후보의 초과/금지 칸 만능 재료 등록은 해제하고 보유 아이템은 소모하지 않는다. 현재 레시피의 지정 선수와 코치 명단도 보존한다.
- 경기에서 승리3/무승부2/패배1 리그 코인. 기본 포인트 복권 보상을 유지한다. 3연승마다 고급 스킬변경권 1장을 추가 우편 지급한다.
- 시즌 목표 9종: 경기20/60/144, 승리10/30/60/90, 팀 홈런10, 팀 탈삼진100. 각 목표의 정확한 아이템·스타·코인 보상은 `app/league-progression.js`의 `LEAGUE_GOALS`와 화면에 표시한다. 목표는 시즌당 한 번 수령하며, 다음 시즌으로 넘어갈 때 달성한 미수령 보상은 자동 정산한다.
- 시즌 완주(정규144경기와 한국시리즈 종료): 레전드 영입 증서1장, 구단선택팩3장, 복권20장, 리그 코인50. 우리 팀 우승 시 코인은100으로 대체하고 기존 우승500스타/복권10장 및 추가 고스변10장/돌파권2장. 시즌별 중복 지급을 막는다. 기존 완료 시즌도 새 완주 보상을 받을 수 있으나 이미 받은 우승 스타는 반복 지급하지 않는다.
- 코인 상점: 고스변15, 돌파권35, 시그니처 계약서80, 시그니처 만능 재료40 코인. 시험용 재화 지원은 기존 항목을 유지하며 리그 코인·영입 증서는 추가하지 않는다.
- 균형/정교/장타/기동력 전술을 경기 전에 선택한다. 보유 카드 원본 능력치는 바꾸지 않고 경기 안에서 정확·파워·주력에 명시된 장단점을 적용한다. 다음 상대와 상대 선발을 미리 보여준다.
- 5경기 빠른 진행도 실제 경기 시뮬레이션, 선발 로테이션, 선수 경험치·피로, 경기별 보상을 모두 적용하고 144경기에서 정지한다. 경기 요약은 실제 생성된 이닝·타격·투구 기록만 사용한다.
- 고스변에서 ‘보라’를 플래티넘 이상으로 세면 정확히2개32%, 3개4%. 1번 확정 및 2·3번 각각20%를 기준으로 한 값이며 레전드 능력 여러 개를 의미하지 않는다.
